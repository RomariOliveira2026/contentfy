# ContentFy — Typography

## Wordmark

O wordmark **ContentFy** é asset proprietário SVG (`brand/svg/logo-horizontal.svg`, `logo-vertical.svg`).  
Não substituir por fontes de sistema no lockup oficial.

## UI

Tipografia de interface segue o stack do produto (UI sans).  
Escalas, pesos e line-height serão documentados aqui conforme o Design System evoluir.

## Regras

- Não alterar o wordmark
- Não usar o símbolo como tipografia decorativa
