# ContentFy — Components

## Objetivo

Inventário e convenções dos componentes de UI da plataforma.

## Áreas principais

- Marketing / landing
- Auth / login
- Marketplace / explore
- Checkout
- Dashboard do produtor
- Área do membro
- Afiliados
- Admin

## Regra de marca

Componentes consomem assets de `/brand` via paths públicos do app **somente após integração explícita** (fora do Design Freeze packing).  
Este documento não altera código — apenas registra o mapa de componentes.
