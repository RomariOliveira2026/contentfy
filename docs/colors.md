# ContentFy — Colors

## Paleta de marca (congelada)

Tokens oficiais de referência em `brand/system-v3/tokens/brand-tokens.css` (quando aplicável) e no Brand Book.

| Token | Uso |
|---|---|
| Midnight `#070B12` | Fundos escuros |
| Charcoal `#111827` | Superfícies / símbolo |
| Orange `#F97316` | Acento primário |
| Amber `#F59E0B` | Acento secundário / íris |
| Gold `#EAB308` | Destaque Fy / lockups |
| Snow `#F8FAFC` | Texto / fundos claros |

## Regras

- Não introduzir novas cores de marca sem aprovação
- UI semântica (sucesso, erro, aviso) pode existir à parte da paleta de brand
